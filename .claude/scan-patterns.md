# Scan Patterns (canonical source)

Single source of truth for safety-scan patterns and tool detection used by `/commit`, `/merge`, `/verify`, `/review`, and `/fix-issue`. Skills reference this file instead of copying patterns — update here, not in individual skills.

---

## Secrets patterns

Grep over diff additions (lines starting with `+`):

- `BEGIN (RSA |EC |OPENSSH |DSA )?PRIVATE KEY`
- `AKIA[0-9A-Z]{16}` (AWS access key)
- `sk_(live|test)_[a-zA-Z0-9]{24,}` (Stripe)
- `ghp_[a-zA-Z0-9]{36}` (GitHub PAT)
- `xox[baprs]-[a-zA-Z0-9-]+` (Slack token)
- Generic: `(?i)(password|api[_-]?key|secret|token|access_key)\s*=\s*["'][^"'$]{8,}` (skip lines containing `$` — likely env var reference)

**Skip:** `.env.example`, `*.template`, test fixtures — unless the value looks real (not `xxx`, `EXAMPLE_KEY`, `your-key-here`).

Match = CRITICAL — stop immediately.

## Protected file patterns

Staged/changed files matching:

- `.env`, `.env.local`, `.env.production`, `.env.staging`
- `.htpasswd`
- `*.pem`, `*.key`, `id_rsa*`, `*.p12`, `*.pfx`

## Debug code patterns

Modified non-test source files only (exclude paths matching `*test*`, `*spec*`, `__tests__/`):

- `console\.log\(`, `console\.dir\(`
- `\bdebugger\b`
- `\bdd\(`, `\bvar_dump\(`, `\bprint_r\(`
- `\bbreakpoint\(\)`, `\bbinding\.pry\b`

## AI-attribution patterns

Commit messages (`git log <base>..HEAD --format='%B'`) and message drafts:

- `Co-Authored-By:` (any value)
- `Generated with`, `Claude Code`, `Anthropic`, `🤖`, `🎯`
- `Assisted-By:`, `Co-Author:`
- Marketing phrases: `Successfully implemented`, `Production-ready`, `Best-in-class`, `Comprehensive`, `Robust`
- First-person on subject line: `^I\s`, `\bI added\b`, `\bI changed\b`, `\bI removed\b`

Grep form for commit history: `grep -iE 'co-authored-by|generated with|claude code|🤖|🎯|Anthropic|Assisted-By'`

Code diff: `grep -iE 'co-authored-by.*claude|generated with.*claude|🤖|# written by ai|// generated by ai'`

## Branch issue-number regex

Extract issue number from branch name: `^(?:gh-|issue-|fix-|feature/)?([0-9]+)`

## Test runner detection

| Detect via | Run command |
|---|---|
| `package.json` with `scripts.test` | `npm test` / `bun test` / `pnpm test` / `yarn test` (per lockfile) |
| `pytest.ini`, `pyproject.toml`, `setup.cfg` | `pytest` |
| `phpunit.xml` | `vendor/bin/phpunit` |
| `go.mod` | `go test ./...` |
| `Cargo.toml` | `cargo test` |
| `Makefile` with `test` target | `make test` |

## Linter detection

| Detect via | Run command |
|---|---|
| `package.json` `scripts.lint`, `.eslintrc*` | `npm run lint` |
| `ruff.toml`, `pyproject.toml [tool.ruff]` | `ruff check` |
| `.flake8` | `flake8` |
| `phpcs.xml` | `vendor/bin/phpcs` |
| `.golangci.yml`, `go.mod` | `golangci-lint run` (if installed) |
| `Cargo.toml` | `cargo clippy` |

Not detected → SKIP with note, never FAIL.
